---
title: A redesigned editor
date: 2026-08-21
summary: The writing toolbar got reorganized into clear groups, table tools now stand out when they're relevant, and save status finally looks like it belongs in Doclix.
---

The editor is the part of Doclix you spend the most time looking at, and it hadn't had a real design pass in a while. This update doesn't change what it does — it changes how it feels to use.

**The toolbar is now two rows instead of one crowded strip.** Formatting tools — headings, bold/italic/strikethrough, lists, links, tables, boxes — live in the top row, grouped by what they do instead of running together as one long line of icons. File import, undo/redo, and version history moved to a second row underneath, alongside save status and the view switcher, so the two rows read as "write" and "manage" rather than one undifferentiated toolbar.

**Table tools only show up when you're in a table, and now they look like it.** When your cursor lands inside a table, the row/column controls appear in a tinted pill labeled "Table" instead of blending into the rest of the icons. It's a small thing, but it makes it obvious those buttons are contextual, not just more formatting options.

**Save status uses Doclix's own visual language.** Instead of a generic icon-and-label pair, the status indicator now uses the same dot-marker style you'll see elsewhere across the product. A word count sits quietly next to it, and the edit/split/preview switcher got a subtle shadow on the active state so it actually reads as a toggle.

Nothing about how you write changed — same shortcuts, same markdown, same autosave. It just looks like it was designed on purpose.
